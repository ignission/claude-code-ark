**Goal:** monorepo 移行後の実在パスを flow / flow-x の安全ガードと開発規約へ反映し、将来パスが移動しても CI とダミー diff テストが偽陰性を検出する状態にする。

**Tech Stack:** bash lib / bash test / Markdown 規約ファイル
