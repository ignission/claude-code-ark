# 常駐するファイルペイン 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PC の `SplitViewPane` を「端末/会話 | ファイル | 図」の 3 ペインにし、ファイルペインにツリー・タブ・CodeMirror での編集と保存・自動再読込を載せる。

**Architecture:** サーバーに ack 形式の `file:open` / `file:list` / `file:write` と購読 (`file:subscribe` → `file:updated`) を足す。クライアントはファイルタブを `useViewerTabs` の端末タブ列から分離した `useFileTabs` に持ち、`SplitViewPane` の中ペイン `FilePane` が描く。モバイルは従来の経路 (`useViewerTabs` + `file:read`) をそのまま使う。

**Tech Stack:** Express + Socket.IO、React 19、CodeMirror 6 (`codemirror` / `@codemirror/language-data` / `@codemirror/theme-one-dark`)、vitest。

設計: `docs/superpowers/specs/2026-10-08-file-pane-design.md`

## Global Constraints

- 書き込みは worktree 内の既存ファイルだけ。`/tmp` 配下と `.git/` 配下は拒否する
- 書き込み上限 2MB (`MAX_EDITABLE_SIZE = 2 * 1024 * 1024`)、テキストの MIME のみ
- 書き込みは同じディレクトリの一時ファイル + `rename`。mode は元のファイルを引き継ぐ
- 最小幅: 左 360px、ファイル 360px、図 320px
- 購読は 1 socket あたり 50 件まで。一覧は 1 ディレクトリ 2,000 件で打ち切る
- socket の payload は外部入力。分割代入の前に型を検証する (同期ハンドラ内の throw はプロセスを落とす)
- モバイルの挙動は変えない (`MobileSessionView` / `MobileLayout` を編集しない)
- コメント・コミットメッセージは日本語。コミットに Co-Authored-By を付けない
- 各タスクの最後に `pnpm check` と該当テストを通す。`pnpm build` は本番の dist を上書きするので実行しない

export const MAX_EDITABLE_SIZE = 2 * 1024 * 1024;

// 既存の FileReadResult に足す
export interface FileReadResult {
  filePath: string; content: string; mimeType: string; size: number;
  mtimeMs: number;
  /** worktree 内・テキスト・2MB 以下のときだけ true */
  editable: boolean;
}

export type FileWriteResult =
  | { ok: true; mtimeMs: number }
  | { ok: false; code: "conflict"; error: string; mtimeMs: number }
  | { ok: false; code: "error"; error: string };

export async function writeFileToWorktree(
  worktreePath: string,
  filePath: string,          // worktree 相対
  content: string,
  expectedMtimeMs: number,
  force?: boolean
): Promise<FileWriteResult>;

export interface DirEntry {
  name: string;
  type: "dir" | "file";
  gitStatus?: "M" | "A" | "?" | "D";
}
export async function listDirectory(
  worktreePath: string,
  dirPath: string            // worktree 相対。ルートは ""
): Promise<{ entries: DirEntry[]; truncated: boolean }>;

/** 監視用に、検証済みの絶対パスを返す (読み取りと同じ規則) */
export async function resolveReadablePath(worktreePath: string, filePath: string): Promise<string>;
```

実装の要点:

- `readFileFromWorktree`: `stat` の `mtimeMs` を返す。`editable` は「`filePath` が相対パス かつ テキスト MIME かつ `size <= MAX_EDITABLE_SIZE`」。`application/octet-stream` でも、先頭 8KB に NUL が無ければテキストとして読む (拡張子表に無い `.gitattributes` 等を開けるようにする)。その場合の `mimeType` は `text/plain`
- `writeFileToWorktree`: 絶対パスは拒否。`resolveSafePath` で realpath を取り、worktree の `.git` 配下なら拒否。`stat` して、ファイルでなければ拒否。`!force && Math.abs(st.mtimeMs - expectedMtimeMs) > 1` なら `conflict`。`Buffer.byteLength(content) > MAX_EDITABLE_SIZE` なら拒否。`<dir>/.<name>.ark-tmp-<pid>-<Date.now()>` へ `writeFile(..., { mode: st.mode })` → `rename`。失敗時は一時ファイルを `rm({ force: true })`。成功後に `stat` し直した `mtimeMs` を返す。例外は投げず `{ ok: false, code: "error" }` に畳む
- `listDirectory`: `resolveSafePath` で解決し `readdir({ withFileTypes: true })`。`.git` を除く。symlink は `stat` で種別を決め、壊れたリンクは file とする。`git check-ignore --stdin -z` (cwd = worktree、`execFile` の非同期、入力は worktree 相対パスを NUL 区切り) で ignore 対象を除く。git が失敗したら何も除かない。`git status --porcelain=v1 -z` の結果から `gitStatus` を付ける (XY のうち `?` → `?`、`A` → `A`、`D` → `D`、それ以外の変更 → `M`。ディレクトリは配下に変更があれば `M`)。status は worktree ごとに 2 秒キャッシュ。dir 先・`localeCompare` 順。2,000 件で打ち切る

  | { ok: true; content: string; mimeType: string; size: number; mtimeMs: number; editable: boolean }

  | { ok: true; entries: FileTreeEntry[]; truncated: boolean }

  | { ok: true; mtimeMs: number }
  | { ok: false; code: "conflict" | "error"; error: string; mtimeMs?: number };

// ClientToServerEvents
"file:open": (data: { sessionId: string; filePath: string }, cb: (r: FileOpenResponse) => void) => void;
"file:list": (data: { sessionId: string; dirPath: string }, cb: (r: FileListResponse) => void) => void;
"file:write": (data: { sessionId: string; filePath: string; content: string; expectedMtimeMs: number; force?: boolean }, cb: (r: FileWriteResponse) => void) => void;
"file:subscribe": (data: { sessionId: string; filePath: string }) => void;
"file:unsubscribe": (data: { sessionId: string; filePath: string }) => void;
// ServerToClientEvents
"file:updated": (data: { sessionId: string; filePath: string }) => void;
```

```ts
// file-handlers.ts
export function createFileHandlers(deps: {
  getWorktreePath: (sessionId: string) => string | undefined;
  watcher: Pick<FileWatcher, "subscribe">;
  emitUpdated: (data: { sessionId: string; filePath: string }) => void;
}): {
  open: (data: unknown, cb: unknown) => Promise<void>;
  list: (data: unknown, cb: unknown) => Promise<void>;
  write: (data: unknown, cb: unknown) => Promise<void>;
  subscribe: (data: unknown) => Promise<void>;
  unsubscribe: (data: unknown) => void;
  /** 切断時に全購読を解除する */
  dispose: () => void;
};
```

実装の要点:

- 各ハンドラは `data` の形と `typeof cb === "function"` を確かめ、不正なら何もせず戻る。ハンドラ全体を try/catch し、例外は `{ ok: false, error }` で返す
- `/tmp/` で始まる `filePath` の `open` は既存の `file:read` と同じ扱い (セッションの存在だけ確かめ、`readFileFromWorktree("", path.resolve(filePath))`)
- `subscribe`: `resolveReadablePath` で絶対パスを得て `watcher.subscribe`。鍵は `JSON.stringify([sessionId, filePath])`。既にあれば何もしない。50 件を超えたら無視する。`await` の後に dispose 済みなら直ちに解除する
- `index.ts`: socket ごとに `createFileHandlers` を作り、`socket.on("file:open", h.open)` 等で登録。`disconnect` で `h.dispose()`。既存の `file:read` は残す

実装の要点:

- `decideOnDiskChange`: `diskMtimeMs` が `loadedMtimeMs` と 1ms 以内なら `ignore` (自分の保存の反響)。違っていて `dirty` なら `show-conflict`、そうでなければ `reload-silently`
- `CodeEditor`: `EditorView` を 1 度だけ作る。拡張は `basicSetup`、`oneDark`、`keymap.of([{ key: "Mod-s", preventDefault: true, run }])`、`EditorState.readOnly` と言語を `Compartment` で差し替える。言語は `LanguageDescription.matchFilename(languages, filePath)?.load()`。`loadSeq` が変わったら、スクロール位置と選択を保って文書全体を差し替える。行のハイライトは `Decoration.line` を `StateField` で持ち、`revealSeq` が変わったら `EditorView.scrollIntoView(pos, { y: "center" })`。フォントは既存の等幅 (`font-mono` と同じ) にし、高さは親に合わせる
- `FileEditor`: マウント時に `api.open` して `api.subscribe`。`file:updated` で `open` し直し、`decideOnDiskChange` に従う。`isVisible` が false の間に届いた更新は印だけ付け、表示されたときに処理する。保存は `detectLineEnding` で読み取り時の改行に戻してから `api.write`。`conflict` ならバナーを出し「上書き保存」で `force: true`。本体の出し分け: `tab.kind === "html"` → `HtmlViewerPane` / `image/*` → `ImageRenderer` / `text/markdown` → 既定はプレビュー (`MarkdownRenderer`) で「編集」に切り替えられる / それ以外 → `CodeEditor`。上部に相対パス・サイズ・「読み取り専用」の印・保存ボタン (dirty のときだけ押せる)。`ok: false` は「ファイルを開けません」+ 理由 (タブは閉じない)
- `FilePane`: 左にツリー (幅 220px、ボタンで折りたたむ。`ark-file-tree-collapsed`)、右にタブバーと本体。タブは全部マウントしたまま `hidden` で切り替える (未保存の編集を保つ)。タブに ● (dirty)。dirty のタブを閉じるときは `window.confirm("保存していない変更があります。閉じますか？")`。dirty が 1 つでもあれば `beforeunload` を張る。タブが 0 枚のときは「ツリーからファイルを選ぶか、会話やボードのリンクを押すと開きます」。`socket` が null の間は何も読まない。`api` は `useMemo` で `[socket, sessionId]` に固定する
- 依存の追加は `pnpm add --filter @ark/web <pkg>`。pnpm 11 は公開 24 時間未満の版を拒否するので、拒否されたら 1 つ前の版を指定する
