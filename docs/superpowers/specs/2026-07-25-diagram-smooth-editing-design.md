# 図解ハーネス: draw.io スムーズ編集 設計

## 目的

図解ハーネスの編集体験を、**ボタン/常時クロム主体**から **draw.io のような直接操作主体**へ移す。キャンバスは無地に保ち、操作は「選択したときだけ」文脈的に現れるようにする。生 JSON 直接編集のような逃げ道に頼らず、kind・カーディナリティ・追加/削除・作成をすべて直接操作で行えるようにする。

## 前提・制約

- **配置モデル = ハイブリッド**: 既定は #248 の座標なし auto-layout（overlap ゼロを構造保証）。ユーザーがドラッグした要素だけ手座標（`ext.x/y`）で「固定（pin）」され、auto 要素はそれを避ける。#248 の manual 優先の自然な延長。
- **注入後サイズ制約**: 編集ハーネスは `diagram-harness.ts` の単一注入文字列で、現状 **119,182 bytes / guard 131,072（残 ~12KB）**。モジュール分割はできない（1文字列）。よってこの再設計は **「旧クロムのコードを削除しながら新ジェスチャを足す差し引き」** で進め、各フェーズ後も `<128KiB` を維持する。guard の閾値は変更しない。
- **非還流の原則を維持**: 座標・レイアウト・kind・cardinality（`ext`）は会話へ非還流。node/edge の追加・削除（構造変更）のみ還流。production `diagram-diff.ts` / `describeModelDiff` は変更しない（#241-243, #248 と同じ契約）。
- **外部リソース禁止**: 図解ハーネスの CSP に従い、CDN/フォント/画像への参照を足さない（inline CSS/SVG のみ）。
- **モバイル非対象**: 編集ハーネスは PC の board ペイン限定（既存どおり）。

## インタラクションモデル（3本柱）

### 柱1: 配置 — ハイブリッド（auto 既定 + drag で pin）
- 既定は auto-layout。`ext.x/y` を持つ要素だけ manual として固定され、auto 要素が避ける（#248 の既存挙動）。
- 要素をドラッグして離すと、その要素に `ext.x/y` が付き pin される（既存の drag 挙動）。
- ダブルクリックした空白位置への新ノード drop も、その座標で pin。

### 柱2: 作成 — hover→方向ハンドル→ドラッグ
- 既存ノードを hover すると周縁に方向ハンドル（#243 のアンカー）が出る。
- ハンドルから**空白へドラッグして離す** → 「**新ノード + そこへの edge**」を一気に作成。新ノードは既定 auto 配置、drop 位置が明示的なら pin。
- ハンドルから**既存ノードへ drop** → edge のみ作成（self-edge/invalid は無効、既存 #243 の閾値・Escape 挙動を踏襲）。
- 新ノードの kind は「直近に選んだ kind」または `kindCandidates` の先頭（作成後に浮くツールバーで変更可能）。

### 柱3: 操作 — 選択時に浮くコンテキストツールバー
- 非選択時、キャンバスは無地（常時ツールバー/常時コントロールなし）。
- 要素を選択すると、その要素の**真上に小さなツールバーが浮く**:
  - **node 選択**: kind ▾ / 「+行」 / 削除
  - **edge 選択**: from-cardinality ▾ / to-cardinality ▾ / 方向 ▾ / 削除
- 選択解除（空白クリック/Escape）で消える。ツールバーは `data-ark-harness-ui` を付け、送信 HTML からは除去される。

## クロム: 消すもの / 残すもの

| 現状 | 変更 |
|---|---|
| ノードパレット（graph/kind select + 「+ノード」） | **削除** → 柱2 の hover ドラッグ作成へ |
| ノード上の「+ 行を追加」ボタン（常時） | **削除** → 浮くツールバーの「+行」＋最終行 Enter |
| 「×」削除ボタン（常時）・kind ピッカー（常時） | **削除** → 浮くツールバー + Delete/Backspace キー |
| edge の cardinality/方向 select（常時/hover） | **削除** → edge 選択時の浮くツールバー |
| 「モデルを直接編集」（生 JSON モーダル） | **既定で隠す**（debug 時のみ。逃げ道を常設しない） |
| 「変更を送る」ボタン | **残す**が最小化（変更検知時だけ控えめに表示） |
| レイアウト方向トグル（LR/TB） | **残す**（グローバル設定。最小の1コントロール） |

## アーキテクチャ

`diagram-harness.ts` の注入編集レイヤに以下を導入する。単一注入文字列のためモジュール分割はせず、**既存ロジックの流用 + 常時描画箇所の撤去**で差し引きを取る。

- **選択 state machine**: `selection = { kind: 'node' | 'edge' | null, id }` を1つ持つ。要素クリックで選択、空白クリック/Escape で解除。
- **浮くツールバー = 単一の再利用コンポーネント**: 選択 state を見て、node 用 / edge 用の中身を出し分ける。#241 の kind ピッカー・#242 の edge コントロール・「+行」の**既存ロジックを流用**し、常時表示していた描画箇所だけ削除する（＝差し引きの原資）。位置は選択要素の `getBoundingClientRect()` から算出し、ビューポート端では上下 fallback（#241/#242 の被り回避の教訓を踏襲）。
- **作成ジェスチャ**: #243 の周縁アンカーの drag ハンドラを拡張し、drop 先が空白なら「新ノード + edge」、既存ノードなら「edge のみ」に分岐する（新規コードは分岐と新ノード生成のみ）。

## 検証（目視・スクショに依存しない）

#248 の教訓に従い、レンダリング目視を acceptance にしない。DOM を計算 assert する。

- 選択で toolbar が要素の上に出る / 非選択で消える / node と edge で中身が変わる。
- hover ハンドル → 空白 drop で node+edge が model に増える / 既存ノード drop で edge のみ増える。
- pin: drag した要素だけ `ext.x/y` が付き、auto 要素には付かない。
- 削除: Delete キー / 浮くツールバーの削除で node と incident edge・`groups[].nodes` 参照が同期除去（参照整合性・422 回避、#243 の契約踏襲）。
- **注入後サイズが各フェーズ後も `<128KiB`**（既存 guard テストで固定）。
- 既存の diagram-harness E2E（overlap・LR/TB・SCC 等）を壊さない。

## フェーズ分割（各フェーズ = 独立に出荷可能な1 Issue・差し引きで size 中立）

| Phase | 内容 | 差し引き |
|---|---|---|
| **A** | 選択 state + 浮くコンテキストツールバー。kind/+行/cardinality/方向/削除を toolbar に集約し、常時表示のコントロールを撤去 | 撤去 ≈ 追加 |
| **B** | hover→方向ハンドル→ドラッグで繋がった新ノード作成。ノードパレット撤去 | 撤去 ≈ 追加 |
| **C** | クロム掃除: 「モデルを直接編集」を debug 送り・「変更を送る」を変更時のみ控えめに・下部ツールバー最小化 | 純減 |
| **D** | 磨き込み: 最終行 Enter で行追加・キーボードショートカット・トランジション・発見性の affordance | 微増（C の純減で吸収） |

順序は A→B→C→D。A で選択/toolbar 基盤を作り、B の新ノードもそれに乗る。各フェーズは `/flow-loop`（codex 実装・Claude レビュー・P2.5 設計承認 / P10 マージの人間ゲート）で回す。

## 非ゴール

- 自由配置（全要素を手座標にする draw.io 完全移植）— ハイブリッドに留める。
- group のネスト・group 一括ドラッグ・snap/grid。
- 図種の新規追加（この設計は既存 graph 図の編集体験の改善）。
- production `diagram-diff.ts` / 会話還流契約の変更。
- モバイルへの編集 UI 追加。
- 生 JSON 直接編集の廃止（debug 用に隠して残す）。
