# 浮かぶパネル (PC の見た目から線をなくす)

- 日付: 2026-10-09
- 状態: 実装する (ユーザー決定。イメージ図4案から「A → D」を選択)
- 手本: Apple の最新のデザイン (Liquid Glass) と Whiteboard

## 1. 目的

PC の画面は、サイドバー・上部バー・ペイン・タブ・一覧を 1px の線で区切っていた。線が多く古く見えるので、
区切りを「すき間・影・面の濃淡」に置き換える。配置と操作は変えない。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 進め方 | A (浮かぶパネル) を先に全体へ入れ、D (「図」のタブの中だけキャンバス) は次の PR |
| 一番下の面 | 色のついた壁紙 (`--wallpaper`)。PC の `SidebarMainLayout` だけに敷く |
| パネル | サイドバー、左 (上部バー + 端末 / 会話)、作業エリアの3枚。8px のすき間で離し、角を丸め、影で浮かせる |
| 上部バー | 左のパネルの中へ移す (作業エリアを開いても、左のパネルの見出しとして残る) |
| リサイザ | パネルの間のすき間そのもの。ふだんは見えず、乗せたときとドラッグ中だけ色が出る |
| 切り替え | 「端末 / 会話」「図 / ファイル / Git」は丸いカプセル。選択中を白いカプセルで持ち上げる |
| パネルの中 | 線を引かず、くぼみ (`--well`) で分ける (ファイルツリー、Git のサイドバーと詳細、ピーク、端末の入力欄) |
| 透明 | 半透明にするのはサイドバーだけ。大きな面に `backdrop-filter` は使わない (ttyd の iframe と CodeMirror が描き直すたびにぼかしが走るため) |
| 暗い配色 | 影が見えないので、パネルを壁紙より明るい面にして浮かせる |

## 3. 範囲外

- モバイル、ダイアログ、shadcn の部品 (`ui/*`)、リポジトリのグリッド表示
- 「図」のタブのキャンバス化 (D。次の PR)
- 図の中身 (`.diagram.html` の投影) の配色

## 4. 確かめること

- 明暗それぞれで、図 / ファイル / Git のタブを撮影して崩れが無いこと
- 左右のリサイザ、Git の上下のリサイザ、サイドバーの幅の変更が動くこと
- 端末 (ttyd) がパネルの角で切れず、入力できること

## 5. D: 「図」のタブのキャンバス (2本目の PR)

| 項目 | 決定 |
|---|---|
| 対象 | デッキ (`type: "deck"`) を積んで見せるとき (既定)。1枚ずつめくる表示、graph の図種、doc は変えない |
| キャンバス | body に点の地を重ねる。地の色は作者が塗った色のまま |
| カード | 各ページを角の丸い、影のあるカードにする。自由形ページにはページの題を札 (`PAGE · 題`) として付ける。内蔵図種 (`SEQ` / `CALL TREE`) は元から札を持つので、枠線を影に替えるだけ |
| 配置 | 左右へ互い違いにずらすだけ。位置は持たない (ドラッグも保存も無い) |
| 操作 | 下の「1枚ずつ」などは、浮いた丸いドックにする |
| コード | 図のリンクから開くコードは、これまでどおり図の横のピーク (A でくぼみのカードにした)。エディタは iframe の中に置けないため、キャンバスの上のカードにはしない |

イメージ図 D との違い: カードを自由に置く・動かす仕組みは作らない。作者が書いたページの配色は変えない。
